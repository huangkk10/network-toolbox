# Ansible Inventory 配置查看器 - 測試指南

## 📋 功能說明

在 Jenkins 詳細頁面（RVT 分析）中添加了「配置」按鈕，點擊後可以查看該 Job 的 Ansible Inventory 配置資訊。

---

## 🎯 測試步驟

### 1. 訪問 RVT 分析頁面

1. 登入系統（Admin 帳號）
2. 點擊頂部的「RVT 分析」選項卡
3. 切換到「Jenkins 詳細」標籤頁

**URL**: `http://localhost/#/rvt-analysis?details`

---

### 2. 測試「配置」按鈕

#### 2.1 找到 Test-KVM01 Job

在 Job 列表中找到 `Test-KVM01`：

- **Job 名稱**: Test-KVM01
- **狀態**: Inactive ⚪
- **操作欄**: 可以看到 [統計] [配置] 兩個按鈕

#### 2.2 點擊「配置」按鈕

點擊 Test-KVM01 的「⚙️ 配置」按鈕：

**預期結果**：
- ✅ 右側滑出 Drawer（寬度 900px）
- ✅ 標題顯示：`Ansible Inventory - Test-KVM01 #148`
- ✅ 顯示快取狀態 Tag（綠色「已快取」或橙色「即時獲取」）
- ✅ 有「重新載入」按鈕

---

### 3. 測試「主機列表」標籤

#### 3.1 檢查主機列表表格

**預期內容**：
- ✅ 顯示 21 個主機
- ✅ 表格欄位：主機名稱、IP 地址、設備號、MAC 地址、使用者、群組、操作
- ✅ 搜尋框正常工作
- ✅ 表格可排序（點擊欄位標題）
- ✅ 分頁功能正常（每頁 10 筆）

#### 3.2 測試搜尋功能

在搜尋框輸入：`Test-KVM01`

**預期結果**：
- ✅ 表格只顯示匹配的主機
- ✅ 顯示「顯示 1 / 21 個主機」

#### 3.3 測試複製功能

點擊任一主機的 IP 地址旁的複製按鈕：

**預期結果**：
- ✅ 顯示「已複製 IP 地址」訊息
- ✅ 剪貼簿包含該 IP（可以貼到記事本驗證）

#### 3.4 測試「查看配置」按鈕

點擊 Test-KVM01 行的「查看配置」按鈕：

**預期結果**：
- ✅ 自動切換到「配置詳情」標籤
- ✅ 自動載入 Test-KVM01 的配置

---

### 4. 測試「群組」標籤

#### 4.1 切換到群組標籤

點擊「群組」標籤：

#### 4.2 測試群組展開/收起

點擊 `PQ1_3` 群組前的箭頭：

**預期結果**：

**預期結果**：
- ✅ 只顯示包含 KVM01 的群組
- ✅ 自動展開匹配的群組
- ✅ 顯示「搜尋結果：X 個群組」Tag

#### 4.4 測試點擊主機

點擊樹狀圖中的 `Test-KVM01` 主機：

**預期結果**：

### 6. 測試快取機制

#### 6.1 首次載入（無快取）

1. 點擊「配置」按鈕
2. 觀察標題列的 Tag

**預期結果**：
- ✅ 顯示橙色「即時獲取」Tag
- ✅ 載入時間較長（2-3 秒）

#### 6.2 再次載入（有快取）

1. 關閉 Drawer
2. 再次點擊「配置」按鈕

**預期結果**：
- ✅ 顯示綠色「已快取」Tag
- ✅ 載入時間很快（< 0.5 秒）

#### 6.3 強制重新載入

1. 點擊右上角的「重新載入」按鈕

**預期結果**：
- ✅ 顯示載入動畫
- ✅ Tag 變為「即時獲取」
- ✅ 重新從伺服器獲取資料

## 🔧 調試技巧

### 檢查 API 請求

打開瀏覽器開發者工具（F12）→ Network 標籤：

1. **獲取完整 Inventory**:
   ```
   GET /api/jenkins-jobs/269/ansible-inventory/
   ```

2. **獲取主機列表**:
   ```
   GET /api/jenkins-jobs/269/ansible-inventory/hosts/
   ```

3. **獲取主機配置**:
   ```
   GET /api/jenkins-jobs/269/ansible-inventory/hosts/Test-KVM01/
   ```

### 檢查 Console 錯誤

打開開發者工具 → Console 標籤：

- 不應該有紅色錯誤訊息
- 正常的日誌訊息（藍色）是可以的

### 檢查 React 組件

使用 React DevTools：

1. 檢查 `AnsibleConfigDrawer` 組件的 props
2. 檢查 state（visible, jobId, jobName, buildNumber）
3. 確認子組件正確渲染
