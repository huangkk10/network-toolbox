# LogsTab 分頁功能更新說明

**更新時間**: 2025-10-27  
**版本**: 1.1.0

## 🆕 新增功能

### 1. 提升最大顯示筆數至 500 行

**之前**:
- 最大可選擇 1000 筆（但可能造成性能問題）
- 默認 200 筆

**現在**:
- 最大 500 筆（平衡性能與數據量）
- 默認 500 筆
- 可選：100 / 200 / 300 / 500 筆

### 2. 新增分頁功能 ⭐

**功能描述**:
- 日誌以分頁方式顯示，提升載入性能
- 可自由選擇每頁顯示數量
- 支持快速跳頁

**分頁選項**:
- 10 條/頁
- 20 條/頁（預設）
- 50 條/頁
- 100 條/頁

**分頁器功能**:
- ⬅️ ➡️ 上一頁 / 下一頁
- 🔢 快速跳轉到指定頁
- 📊 顯示總條數（如：共 500 條日誌）
- 🔄 可調整每頁顯示數量

## 📊 界面變更

### 統計資訊欄

**之前**:
```
顯示: 200 行 / 最多 200 行 | INFO: 100 | WARN: 34 | ERROR: 54 | DEBUG: 12
```

**現在**:
```
總計: 500 行 | 當前頁: 20 行 | INFO: 223 | WARN: 92 | ERROR: 134 | DEBUG: 51
```

**說明**:
- **總計** - 總共載入的日誌數量
- **當前頁** - 當前頁面顯示的日誌數量
- **各級別數量** - 在所有載入的日誌中的統計

### 分頁器位置

分頁器位於日誌內容區底部：

```
┌────────────────────────────────────────────┐
│  日誌內容                                   │
│  ┌────────────────────────────────────┐   │
│  │ 2025-10-27 10:15:23  INFO  DHCP... │   │
│  │ 2025-10-27 10:16:10  INFO  DHCP... │   │
│  │ ...（顯示 20 條）...                │   │
│  └────────────────────────────────────┘   │
│                                            │
│  ┌────────────── 分頁器 ─────────────┐    │
│  │ 共 500 條日誌                      │    │
│  │ [<] 1 2 3 ... 25 [>]  每頁: [20▼] │    │
│  └────────────────────────────────────┘    │
└────────────────────────────────────────────┘
```

## ⚙️ 技術實現

### 前端狀態管理

新增兩個狀態：

```javascript
const [currentPage, setCurrentPage] = useState(1);      // 當前頁碼
const [pageSize, setPageSize] = useState(20);           // 每頁顯示數量
```

### 分頁計算

```javascript
// 獲取當前頁的日誌
const getCurrentPageLogs = () => {
    const startIndex = (currentPage - 1) * pageSize;
    const endIndex = startIndex + pageSize;
    return logs.slice(startIndex, endIndex);
};
```

### Ant Design Pagination 組件

```javascript
<Pagination
    current={currentPage}
    pageSize={pageSize}
    total={logs.length}
    onChange={handlePageChange}
    onShowSizeChange={handlePageChange}
    showSizeChanger              // 顯示每頁數量選擇器
    showQuickJumper              // 顯示快速跳轉
    showTotal={(total) => `共 ${total} 條日誌`}
    pageSizeOptions={['10', '20', '50', '100']}
/>
```

## 📈 性能優化

### 渲染優化

**之前**:
- 一次渲染所有日誌（可能 500+ 條）
- DOM 節點過多，滾動卡頓

**現在**:
- 只渲染當前頁日誌（最多 100 條）
- DOM 節點減少 80%+
- 滾動流暢

### 載入優化

**API 請求**:
- 仍然一次載入所有日誌（最多 500 條）
- 前端分頁處理，無需額外請求

**記憶體使用**:
- 載入的數據量不變
- 但渲染的 DOM 節點大幅減少

## 🔧 配置說明

### 默認配置

```javascript
limit: 500        // 從 API 載入 500 條日誌
pageSize: 20      // 每頁顯示 20 條
currentPage: 1    // 從第 1 頁開始
```

### 可調整範圍

| 配置 | 最小值 | 默認值 | 最大值 | 說明 |
|------|--------|--------|--------|------|
| **顯示筆數 (limit)** | 100 | 500 | 500 | API 載入的總日誌數 |
| **每頁數量 (pageSize)** | 10 | 20 | 100 | 單頁顯示的日誌條數 |

## 📝 行為說明

### 自動重置頁碼

以下操作會自動重置到第 1 頁：

1. ✅ 切換 DHCP Server
2. ✅ 改變日誌等級過濾
3. ✅ 輸入關鍵字搜尋
4. ✅ 切換日誌來源（本地/遠端）
5. ✅ 改變顯示筆數
6. ✅ 點擊「重新載入」
7. ✅ 改變每頁顯示數量

### 保持頁碼

以下操作保持當前頁碼：

1. ⏸️ 開啟/關閉自動更新
2. ⏸️ 翻頁操作

## 🐛 已知限制

1. **分頁是前端實現**
   - 所有日誌仍需一次性載入
   - 不支援後端分頁（未來可改進）

2. **自動更新時的頁碼**
   - 自動刷新後會重置到第 1 頁
   - 確保看到最新日誌

3. **下載功能**
   - 下載所有載入的日誌（非當前頁）
   - 符合預期，可下載完整數據
